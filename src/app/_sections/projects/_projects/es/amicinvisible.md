---
description: "Una aplicación web para organizar grupos de amigo invisible con amigos y familia"
---

Una aplicación web para organizar grupos de [amigo invisible](https://en.m.wikipedia.org/wiki/Secret_Santa) con amigos y familia. La creé como prototipo, con la idea de reescribirla más adelante.

Puedes crear grupos, invitar a gente con un enlace o con el menú de compartir del móvil, sortear quién regala a quién y compartir una lista de deseos para dar ideas de regalos.
