A multiplayer Minesweeper game I built to learn Socket.IO and Node.js, inspired by Minesweeper Flags.

The game communicates in real time and saves its state on the server. It includes chat, editable user profiles, configurable web and desktop notifications, and a game list with board previews so you can follow several games at once.

I built it with React, Socket.IO, Material UI, Tailwind CSS, and MongoDB.

Read more in my blog post, [Multiplayer Minesweeper with Socket.IO](/blog/multiplayer-minesweeper-with-socket-io).
